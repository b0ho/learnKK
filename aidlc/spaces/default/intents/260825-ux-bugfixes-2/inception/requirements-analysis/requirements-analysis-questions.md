# Requirements Analysis — 질문/결정 (ux-bugfixes-2)

사용자가 11개 수정 항목을 명시적으로 지정하여 열린 질문은 없다. 해석이 필요한 항목은 아래 결정으로 확정한다(가이드 모드 아님 — 사용자 지정 기반).

## 확정된 해석 (Decisions)

### D-1 (FR-1) 활성 탭 재클릭 동작
- **결정**: 현재 탭을 재클릭하면 탭 루트로 이동 + 데이터 재조회.
- [Answer]: 탭 루트 리셋 + reload (사용자 지정 "새로고침")

### D-2 (FR-7) "멘토에 대한 수료 판정"
- **결정**: 소유 멘토가 자기 모임의 수료 판정(compute)을 버튼으로 실행. 백엔드는 이미 owning-mentor OR admin 허용이므로 FE 진입점만 추가.
- [Answer]: 소유 멘토의 compute 버튼(운영 허브 수료 판정 영역)

### D-3 (FR-6) 완료 게이트
- **결정**: allScheduledSessionsEnded 게이트를 제거/완화하여 세션 미종료여도 완료 처리 허용.
- [Answer]: 게이트 제거(상태 전이 조건만 유지)

### D-4 (FR-11) 시드 적용 방식
- **결정**: V12 마이그레이션으로 자연키 기반 멱등 삽입(ON CONFLICT DO NOTHING). 기존 데이터 비파괴 공존.
- [Answer]: V12 신규 추가, 멱등
