# 성능 테스트 지침 — learnKK ux-bugfixes

## 적용 여부
해당 없음. 이번 스코프는 UX/기능 버그픽스(Minimal)이며 성능 NFR 목표가 정의되지 않았다. 신규 로직은 기존 read/write 경로에 국소 추가(세션 완료 플래그, 상태 역전이, 상태별 목록 조회)로 성능 특성 변화가 없다.

## 참고 (향후 필요 시)
- 관리자 상태별 목록(`GET /api/admin/meetings?status=`)은 인덱스된 `status` 컬럼 조회이며 소규모 운영 가정. 대규모 데이터에서 페이지네이션/인덱스 점검이 필요하면 그때 성능 시나리오를 추가한다.
