## Problem Statement (핵심 문제)

러닝 크루(함께 배우는 learning 모임)를 운영하려 해도, 모집·학습자료·공지·출석·수료 판정 같은 운영 활동이 여러 도구에 흩어져 있어 체계적으로 진행하기 어렵다. [Q1]

현재는 wiki 기반으로 소통·운영하고 있어 접근성이 낮고, 관리자가 전체 모임 현황을 모니터링하거나 품질을 관리할 수단도 마땅치 않다. [Q2]

learnKK는 개설 → 승인 → 모집 → 주차별 진행(자료·공지·쪽지·출석) → 수료 판정 → 설문·피드백에 이르는 전 과정을 하나의 모바일 웹뷰 플랫폼으로 통합해, 흩어진 운영을 한 흐름으로 묶는 것을 목표로 한다. [desc] [Q1]

## Target Customer (대상 사용자)

세 종류의 역할이 하나의 플랫폼을 공유한다. [desc]

- 멘토(mentor) — 모임을 개설하고 운영하는 주체. 현재는 공지·자료·출석·수료를 수작업으로 관리해야 하는 부담이 크다. [desc] [Q2]
- 멘티(mentee) — 모임에 신청·참여하는 학습자. 어떤 모임이 열리는지, 내 신청·진행 상황이 어떤지 한눈에 보기 어렵다. [desc] [Q2]
- 시스템 관리자(system admin) — 전체 모임을 감독하고 수료 여부를 판단하는 운영 주체. 현황 모니터링과 품질관리 수단이 없고, 특이사항이 생겼을 때 소통 채널도 부족하다. [desc] [Q2]

주된 페인포인트: 관리자의 전체 현황 모니터링·품질관리 부재, 그리고 현재 wiki 기반 소통의 낮은 접근성. [Q2]

## Success Metrics (성공 지표)

가장 중요한 성공 정의는 "모임이 기간 내에 정상적으로 굴러가고 수료로 이어지는가"이다. [Q3]

- 멘토 성공 — 주어진 학습 기간 동안 계획된 학습 활동(주차별 모임) 회수를 전부 진행·완료함. [Q3]
- 멘티 성공(수료 기준) — 주어진 학습 기간 동안 출석율 80% 이상을 달성함(80%가 수료 인정의 임계값). [Q3]

보조 지표(부차적): [Q3]

- 개설 대비 승인 모임 수, 모집 충족률 [Q3]
- 평균 출석율·수료율 [Q3]
- 멘티 만족도(과정 설문)·멘토 재개설률 [Q3]

## Initiative Trigger (시작 계기)

- 사내/커뮤니티의 학습 문화 활성화 필요 [Q4]
- 기존 wiki 기반의 수작업·분산 운영을 대체할 전용 도구 필요 [Q4]
- 학습/교육 프로그램 운영 방식을 검증하기 위한 파일럿 성격 [Q4]

## Initial Scope Signal

- 이번 워크플로우는 workflow-selected 스코프 `learning-crew-local-mvp`(설계 중심)로 진행한다 — 이데이션과 인셉션을 거쳐 상세 설계(functional-design, nfr-requirements)까지 하고, 실제 구현(code-generation)·배포·운영은 팀원별 개별 구현 워크플로우로 분리한다. [scope]
- 첫 버전에 반드시 포함되는 핵심 여정(전체): 회원가입·프로필(관심사 해시태그·한 줄 소개) → 모임 목록 탐색; 멘토 모임 개설 → 관리자 승인 → 모집·신청(멘티 설문); 주차별 진행(자료실·공지·쪽지) → 출석(모임 시작/종료·출석 체크); 출석율 기반 수료 판정 → 과정 설문 → 멘토 완료 인정·피드백 확인; 관리자 모니터링 + 관리자 ↔ 멘토/멘티 쪽지. [Q6]
- 플랫폼 형태: 모바일 웹뷰 우선(다른 환경 미고려), 전부 로컬 환경 개발, 외부 서비스(AWS 등) 미사용. [desc]
- 디자인/UX 방향: 온라인 클래스/코호트 러닝 결(클래스101·인프런형 기간제 코스 진행)을 참고 기준으로 삼는다. [Q5]

## 용어 (Glossary)

- 러닝 크루(learning crew) — 특정 기간 동안 특정 주제를 함께 학습하는 모임. [desc]
- 멘토 / 멘티 / 시스템 관리자 — 각각 모임 개설·운영 / 신청·참여 / 감독·수료 판정 주체. [desc]
- 수료(completion) — 멘티가 기간 내 출석율 80% 이상을 충족해 학습을 완료했다고 인정받는 것. [Q3]
- 주차(week session) — 학습 기간을 나눈 회차 단위의 학습 모임. [desc]
