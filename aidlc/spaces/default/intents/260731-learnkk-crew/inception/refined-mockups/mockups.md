## 개요·기준

- **대상:** 모바일 웹뷰 세로(대표 폭 360~430px). 태블릿/데스크톱은 이번 범위 밖(확대 대응만, design-system-mapping 참조). [requirements NFR1, Q5]
- **디자인 시스템:** shadcn/ui(Radix primitives + Tailwind) 우선, 불가 시 유사 헤드리스 라이브러리 탐색. 상세 컴포넌트 매핑은 `design-system-mapping.md`. [Q2]
- **상태 커버리지:** 주요 화면마다 로딩 / 빈(empty) / 오류(재시도) / 성공을 명세(stories CC-3). [Q4]
- **접근성:** 각 화면 접근성 주석 + `accessibility-checklist.md`(기본 준수, WCAG 인증 목표 아님). [requirements NFR7, Q6]
- **정보구조(IA):** rough-mockups 제안 유지 — 전역 헤더(제목 + 쪽지 아이콘), 하단 3탭(모임 / 내 러닝(역할 적응형) / 내정보). [wireframes]
- **rev2 변경 요약:** 가입에 사번(화면 9), 신청과 사전설문 분리(화면 2 신청 즉시 + 화면 3 설문은 ②시작 후), 멘토 세션 일정 관리(화면 5) + 멘티 팝업 출석(화면 10 신규), 출석률 세션 기준(화면 4·6). [stories rev2]

## 상태 어휘 매핑 (canonical ↔ 사용자 라벨) [Q7]

| canonical 상태 | 목록 필터/뱃지 라벨 | 비고 |
|---|---|---|
| 개설신청 | (멘토 본인/관리자만 노출) | 탐색 목록엔 미노출 |
| 모집중 | 모집중 | 신청 가능 |
| 시작대기 | 모집마감 | 모집 확정~②시작 전 |
| 진행중 | 진행중 | 세션·출석 진행 |
| 완료 | 종료 | 수료 확정 단계 |
| 반려 | (멘토 본인/관리자만) | 종료 상태 |
| 취소 | (해당 신청자/관리자만) | 종료 상태 |

목록 필터는 사용자 친화 라벨(모집중/진행중/모집마감/종료)을 쓰되 내부적으로 canonical에 매핑한다.
