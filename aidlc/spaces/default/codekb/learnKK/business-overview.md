# 비즈니스 개요 — learnKK (런크크)

## 도메인과 목적
learnKK는 사내 멘토링 러닝 플랫폼이다. 멘토가 모임(스터디/러닝)을 개설하고, 관리자가 4개 지점(① 개설 ② 시작 ③ 완료 ④ 멘티 수료)에서 승인하며, 멘티가 선착순으로 신청·참여한다. 참여 중에는 세션 일정·팝업 출석·자료실/공지·쪽지·사전설문/피드백이 오간다.

## 핵심 사용자와 역할
- **멘토(MENTOR)**: 모임 개설, 사전설문 문항 구성, 세션 일정 관리, 자료/공지 작성, 피드백/사전설문 응답 열람.
- **멘티(MENTEE)**: 모집중 모임 신청/취소, 자료 열람, 사전설문 응답, 세션 출석, 피드백 제출.
- **관리자(ADMIN)**: 모임 라이프사이클 승인(①~③), 멘티 수료 확정(④). 가입 API로는 생성 불가(DB 승격).

## 주요 기능 흐름 (U1~U8)
- **U1 Contracts&Kernel / U2 Auth&Shell**: 사번 가입·로그인·RBAC, 공유 계약(OpenAPI/DTO/DB).
- **U3 Meeting**: 상태머신(PENDING_APPROVAL→RECRUITING→READY_TO_START→IN_PROGRESS→COMPLETED, +REJECTED/CANCELLED), 사전설문 문항 빌더.
- **U4 Enrollment**: 선착순 신청(정원·중복 제어), 취소.
- **U5 Session/Attendance**: 세션 일정, 시간창 팝업 출석, 출석율, 80% 자동 수료 판정, ④ 관리자 확정.
- **U6 Content**: 주차별 게시글·첨부(BLOB)·공지, 참여자 열람 권한.
- **U7 Messaging**: 1:1 쪽지 스레드, 안읽음 뱃지, 권한 경계.
- **U8 Survey/Feedback**: 사전설문 응답(②시작 후), 과정 피드백.
- **U9 Admin/Monitoring**: 승인 큐·모니터링 (Bolt 8, 미구현).

## 현재 버그픽스 범위 (이번 intent)
설문 선택지 쉼표 입력, 관리자 승인 화면 리스트/영역화·되돌리기·확인 다이얼로그·네비 '관리', 세션 삭제/완료, 자료실 강조, 사전설문 상시 수정, 피드백/사전설문 분리, 신청 취소 후 재신청 — 총 12건의 UX/기능 개선.
